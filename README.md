# Saladbox

A sandbox physics simulator. Mess around, find out.

Built with LibGDX 1.12.1.

## Requirements

- JDK 8+
- LibGDX 1.12.1 (fetched via Gradle)

## Running

```
cd test
./gradlew desktop:run
```

On Windows use `gradlew.bat desktop:run`.
